# Discord-бот для анонимных сообщений (`/anonim_message`)

Локальный Discord-бот на **Python 3.11+** и **discord.py 2.x**, позволяющий участникам сервера отправлять полностью анонимные сообщения в общий чат через slash-команду `/anonim_message`.

Бот не требует базы данных, веб-сервера, Docker или облачного хостинга — запускается напрямую из терминала на вашем компьютере.

---

## Возможности и принцип работы

1. Участник заходит в специальный канал приёма команд (`ANON_CHANNEL_ID`) и вводит:
   ```text
   /anonim_message text: я спёр у вас шоколад вчера
   ```
2. Бот проверяет канал вызова и валидирует текст (не пустой, не только пробелы, длина до **1900** символов).
3. В общий канал (`PUBLIC_CHANNEL_ID`) бот от **своего имени** публикует аккуратный Embed с заголовком **«Анонимное сообщение»** — без имени, никнейма, ID, аватара, упоминаний или времени отправителя. Все пинги (`@everyone`, `@here`, роли и пользователи) принудительно заблокированы.
4. Автору команды приходит скрытый (*ephemeral*) ответ **«Сообщение отправлено анонимно»**, который видит только он сам.
5. В терминале на ПК владельца бота ведётся подробный журнал вызовов (включая ID/имя автора и текст сообщения) для модерации.

- ОС: **Windows**, **Linux** или **macOS**

## Пошаговая настройка с нуля (инструкция для новичка)

### 1. Создание приложения в Discord Developer Portal

1. Откройте [Discord Developer Portal](https://discord.com/developers/applications) и войдите в свой аккаунт Discord.
2. Нажмите кнопку **New Application** в правом верхнем углу.
3. Введите имя приложения (например, `Анонимные сообщения`), примите условия и нажмите **Create**.

### 2. Создание бота и получение токена

1. В левом меню вашего приложения перейдите на вкладку **Bot**.
2. При необходимости задайте имя и аватар бота.
3. В блоке **Token** нажмите кнопку **Reset Token** (подтвердите действие и при запросе введите код 2FA).
4. Нажмите **Copy** и временно сохраните токен в надёжном месте — позже вы вставите его в файл `.env` в переменную `DISCORD_TOKEN`.

> **Важно:** никогда не публикуйте токен в чатах, скриншотах или Git-репозиториях. Любой, у кого есть токен, получает полный контроль над ботом.

### 3. Настройка Intents (Privileged Gateway Intents)

На той же вкладке **Bot** прокрутите страницу до раздела **Privileged Gateway Intents**:

- **Presence Intent** — оставьте **выключенным**
- **Server Members Intent** — оставьте **выключенным**
- **Message Content Intent** — оставьте **выключенным**

**Привилегированные интенты этому боту не нужны** — он работает через современные slash-команды (`app_commands`) и использует стандартные `discord.Intents.default()`.

### 4. Генерация ссылки приглашения (Invite URL) и права бота

1. В левом меню перейдите в **OAuth2** → **URL Generator** (или прокрутите вкладку **OAuth2** до блока **OAuth2 URL Generator**).
2. В блоке **SCOPES** отметьте две галочки:
   - `bot`
   - `applications.commands`
3. Ниже появится блок **BOT PERMISSIONS**. Отметьте в нём следующие права:
   - `View Channels` *(Просмотр каналов)*
   - `Send Messages` *(Отправка сообщений)*
   - `Embed Links` *(Встраивание ссылок)*
   - `Use Application Commands` *(Использование слеш-команд)*
4. В самом низу страницы скопируйте ссылку из поля **Generated URL**.
5. Откройте скопированную ссылку в браузере, выберите ваш сервер из выпадающего списка, нажмите **Продолжить** → **Авторизовать** и пройдите проверку капчи.

> **Совет по настройке каналов:** если каналы для приёма команд или публикации закрытые (приватные), зайдите в «Настройки канала» → «Права доступа» на самом сервере и убедитесь, что у роли бота включены права `View Channel`, `Send Messages` и `Embed Links`.

### 5. Включение Developer Mode и копирование ID сервера и каналов

Чтобы узнать числовые ID сервера и каналов в Discord:

1. Откройте приложение Discord → нажмите на шестерёнку **Настройки пользователя** (*User Settings*) внизу слева.
2. Перейдите в раздел **Расширенные** (*Advanced*) в блоке «Настройки приложения».
3. Включите переключатель **Режим разработчика** (*Developer Mode*) и закройте настройки.
4. Скопируйте три нужных ID:
   - **ID сервера (`GUILD_ID`)**: нажмите правой кнопкой мыши по названию/иконке вашего сервера → **Копировать ID сервера** (*Copy Server ID*).
   - **ID канала для ввода команд (`ANON_CHANNEL_ID`)**: создайте или выберите специальный текстовый канал (например, `#отправить-анонимку`), нажмите по нему правой кнопкой мыши → **Копировать ID канала** (*Copy Channel ID*).
   - **ID общего канала (`PUBLIC_CHANNEL_ID`)**: нажмите правой кнопкой мыши по общему текстовому каналу, куда должны публиковаться анонимные сообщения (например, `#общий-чат` или `#анонимки`), → **Копировать ID канала** (*Copy Channel ID*).

### 6. Создание и настройка файла `.env`

В корне проекта уже есть шаблон `.env.example`. Скопируйте его в файл `.env`:

- **Windows (CMD):**
  ```bat
  copy .env.example .env
  ```
- **Windows (PowerShell):**
  ```powershell
  Copy-Item .env.example .env
  ```
- **Linux / macOS:**
  ```bash
  cp .env.example .env
  ```

Откройте созданный файл `.env` в любом текстовом редакторе и подставьте ваши значения:

```env
DISCORD_TOKEN=ваш_реальный_токен_бота
GUILD_ID=123456789012345678
ANON_CHANNEL_ID=123456789012345679
PUBLIC_CHANNEL_ID=123456789012345680
LOG_LEVEL=INFO
```

#### Описание переменных `.env`

| Переменная | Обязательна | Описание |
| :--- | :---: | :--- |
| `DISCORD_TOKEN` | Да | Секретный токен бота из вкладки **Bot** в Discord Developer Portal. |
| `GUILD_ID` | Рекомендуется | Числовой ID вашего Discord-сервера. **Настоятельно рекомендуется указать `GUILD_ID`**: тогда slash-команда `/anonim_message` синхронизируется на сервере мгновенно при запуске. Если оставить `GUILD_ID` пустым, выполнится глобальная синхронизация, которая в Discord может занимать до 1 часа. |
| `ANON_CHANNEL_ID` | Да | ID текстового канала, в котором разрешено вызывать `/anonim_message`. В любых других каналах команда вернёт скрытую ошибку. |
| `PUBLIC_CHANNEL_ID` | Да | ID общего текстового канала, куда бот отправляет готовые анонимные Embed-сообщения. |
| `LOG_LEVEL` | Нет | Уровень подробности логов в терминале (`DEBUG`, `INFO`, `WARNING`, `ERROR`, `CRITICAL`). По умолчанию `INFO`. |

## Установка и запуск

Откройте терминал в папке проекта и выполните команды:

```bash
python -m venv .venv
# активация venv для Windows/Linux
pip install -r requirements.txt
python main.py
```

### Подробные команды по операционным системам

#### Windows (PowerShell)
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```
*(Если PowerShell заблокировал выполнение скрипта активации, выполните один раз `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` или используйте CMD).*

#### Windows (Командная строка CMD)
```bat
python -m venv .venv
.venv\Scripts\activate.bat
pip install -r requirements.txt
python main.py
```

#### Linux / macOS
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

Чтобы остановить бота, нажмите `Ctrl + C` в окне терминала.

## Как пользоваться ботом

1. Убедитесь, что бот запущен в терминале и вывел сообщение `Бот онлайн` и `Синхронизация команд завершена`.
2. Перейдите в Discord на ваш сервер в канал, ID которого указан в `ANON_CHANNEL_ID`.
3. В поле ввода сообщения начните печатать `/anonim_message`, выберите команду из всплывающего меню и введите текст в параметр `text`:
   ```text
   /anonim_message text: я спёр у вас шоколад вчера
   ```
4. Нажмите `Enter`:
   - Вы получите скрытое сообщение от бота: **«Сообщение отправлено анонимно»** (оно видно только вам).
   - В канале `PUBLIC_CHANNEL_ID` появится сообщение от имени бота с заголовком **«Анонимное сообщение»** и вашим текстом — без каких-либо сведений об авторе.

### Встроенные ограничения и защита
- Вызов команды в любом другом канале (не `ANON_CHANNEL_ID`) отклоняется со скрытой ошибкой без публикации сообщения.
- Команда недоступна в личных сообщениях бота (`guild_only`).
- Пустые сообщения и сообщения из одних пробелов отклоняются.
- Максимальная длина текста — **1900 символов**.
- Упоминания `@everyone`, `@here`, ролей и пользователей не вызывают уведомлений (`AllowedMentions.none()`).

## Проверка терминальных логов

Все логи выводятся в стандартный поток вывода (`stdout`) прямо в окно терминала, в котором запущен `python main.py`. Токен бота никогда не выводится в лог.

### Пример логов при успешном запуске
```text
2026-10-26 15:20:00 | INFO     | anon_bot.startup | Инициализация бота | discord.py=2.7.1 | guild_id=123456789012345678 | anon_channel_id=123456789012345679 | public_channel_id=123456789012345680 | log_level=INFO
2026-10-26 15:20:02 | INFO     | anon_bot | Бот онлайн | discord.py=2.7.1 | bot=AnonBot#1234 (id=987654321098765432) | guild_id=123456789012345678 | anon_channel_id=123456789012345679 | public_channel_id=123456789012345680
2026-10-26 15:20:02 | INFO     | anon_bot | Синхронизация команд завершена (guild_id=123456789012345678): синхронизировано 1 (/anonim_message)
```

### Пример логов при вызове `/anonim_message` и успешной публикации
```text
2026-10-26 15:21:10 | INFO     | anon_bot | ANON | ts=2026-10-26T15:21:10+00:00 | guild=123456789012345678 name='MyServer' | user=ivan_user username='ivan_user' id=456789012345678901 global_name='Иван' display_name='Ваня' nick='Ваня' | anon_channel=123456789012345679 channel_name='отправить-анонимку' | text='я спёр у вас шоколад вчера'
2026-10-26 15:21:10 | INFO     | anon_bot | ANON_SENT | public_channel=123456789012345680 | message_id=112233445566778899 | text_length=26
```

По этим строкам администратор в терминале всегда видит:
- точное время вызова (`timestamp`),
- сервер (`guild`, `name`),
- данные отправителя (`id`, `username`, `global_name`, `display_name`, серверный `nick`),
- канал вызова (`anon_channel`, `channel_name`),
- полное содержимое сообщения в безопасном `repr`-формате,
- ID опубликованного сообщения (`message_id`), ID публичного канала и длину текста,
- полный `traceback` в случае любых ошибок доступа или API.
